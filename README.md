# Catálogo de Produtos

## Objetivo
Aplicação web de catálogo de produtos com carrinho de compras, desenvolvida com Vue.js 3 e Vite.

## Tecnologias
- Vue.js 3
- Vite
- JavaScript
- CSS3

## Funcionalidades
- Exibição de produtos em cards (imagem, nome e preço)
- Campo de busca em tempo real (filtra por nome)
- Contador de itens no carrinho atualizado sem recarregar a página
- Layout responsivo

## Como executar

```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev
```

Abra `http://localhost:5173` no navegador.
